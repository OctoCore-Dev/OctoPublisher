Ключевые возможности v1.4.2

Парадигма Store as Code

Описания, локали, иконки, скриншоты, ассеты Xbox и трейлеры хранятся в Git в каталоге packaging/ и деплоятся автоматически.

5-Уровневый предполётный линтер

Команда octopublish test проверяет заглушки TODO, лимиты символов, геометрию картинок и валидность MP4 до коммита.

Защита Safe-Merge

Предотвращает фатальные ошибки 403 Forbidden в Google Play, автоматически подтягивая текущее название при обновлении листинга.

Xbox и MP4 Трейлеры (v1.4.2)

Ассеты Xbox (1080x1080, 2160x2160) и безаллокационный парсер заголовков MP4-видео VideoMetadataReader без вызова внешнего FFmpeg.

Store as Code: Управление метаданными в Git

OctoPublisher полностью автоматизирует синхронизацию описаний, скриншотов и релиз-ноутов со страницами сторов.

1. octopublish init

Создаёт дерево каталогов с русскими шаблонами и валидными PNG.

octopublish init all --dir packaging

2. octopublish pull

Выгружает реальные описания, иконки и скриншоты напрямую из сторов.

octopublish pull windows 9NZXP5WR803J

3. octopublish add

Добавляет новый язык по короткому коду (en, fr, de, es, zh, etc.).

octopublish add all en --dir packaging

4. octopublish test

5-уровневый линтер для валидации перед коммитом или деплоем в CI.

octopublish test --dir packaging

5. octopublish list

Выводит сводную таблицу статуса готовности текстов и скриншотов.

octopublish list --dir packaging

Установка и интеграция

Глобальная установка через .NET CLI

Требуется установленный .NET 10 SDK (или .NET 8/9).

dotnet tool install --global OctoPublisher

После установки команда octopublish доступна в любой консоли (PowerShell, Bash, CMD, zsh).

Обновление до последней версии

dotnet tool update --global OctoPublisher

Модуль Microsoft Store (mstore)

Автоматизирует работу с Dev Center Ingestion API и параллельную загрузку в Azure Blob.

Публикация пакета MSIX

Командная строка
octopublish mstore publish \
  --package "./bin/Release/App.msix" \
  --app-id "9NZXP5WR803J" \
  --notes-dir "./packaging/whatsnew" \
  --desc-dir "./packaging/store/windows"

Инспекция статуса

Проверяет текущую фазу сертификации в Partner Center.

octopublish mstore status --app-id 9NZXP5WR803J

Очистка черновика

Удаляет зависший нескоммиченный черновик отправки.

octopublish mstore delete-draft --app-id 9NZXP5WR803J

Модуль Google Play Store (playstore)

Прямая интеграция с Google Play Developer API v3 через сервисный аккаунт.

Публикация AAB бандла

Командная строка
octopublish playstore publish \
  --bundle "./bin/Release/App.aab" \
  --package-name "dev.octocore.obxodka" \
  --service-account "$PLAY_CONFIG_JSON" \
  --track "production" \
  --notes-dir "./packaging/whatsnew" \
  --desc-dir "./packaging/store/android"

Xbox Store и Видео-трейлеры (v1.4.2)

Начиная с версии 1.4.2 движок поддерживает полную спецификацию графических ассетов Xbox Series X|S и Xbox One, а также встроенную валидацию MP4-трейлеров.

Xbox StoreLogos

Для публикации на консолях Xbox требуются квадратные логотипы высокого разрешения:

  • StoreLogo_1080x1080.png (Full HD квадрат)
  • StoreLogo_2160x2160.png (4K Ultra HD для Xbox Series X)

VideoMetadataReader (Zero Alloc)

Встроенный чистый парсер стандарта ISO/IEC 14496-12 (ISO BMFF). Анализирует боксы ftyp, moov, mvhd, trak, mdhd напрямую через ReadOnlySpan<byte> без внешних бинарников (FFmpeg / ffprobe) и без утечек памяти.

Структура каталога трейлеров и Xbox

packaging/store/windows/ru-RU/ ├── xbox/ │ ├── xbox-1080.png # 1080x1080 32-bit PNG │ └── xbox-2160.png # 2160x2160 32-bit PNG (4K) └── trailer/ ├── trailer.mp4 # 1920x1080 H.264/AAC MP4 видео └── trailer-thumbnail.png # 1920x1080 PNG заставка (16:9)

GitHub Actions CI/CD Workflow

Готовый шаблон для автоматического тестирования и релиза при создании git-тега.

.github/workflows/release-stores.yml
name: Релиз в магазины приложений on: push: tags: ['v*'] jobs: validate: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Установка .NET 10 uses: actions/setup-dotnet@v4 with: { dotnet-version: '10.0.x' } - name: Установка OctoPublisher run: dotnet tool install -g OctoPublisher - name: Предполётная проверка run: octopublish test --dir packaging publish-windows: needs: validate runs-on: windows-latest steps: - uses: actions/checkout@v4 - name: Публикация MSIX в Microsoft Store env: STORE_TENANT_ID: ${{ secrets.STORE_TENANT_ID }} STORE_CLIENT_ID: ${{ secrets.STORE_CLIENT_ID }} STORE_CLIENT_SECRET: ${{ secrets.STORE_CLIENT_SECRET }} STORE_APP_ID: ${{ secrets.STORE_APP_ID }} run: octopublish mstore publish --package ./App.msix --desc-dir packaging/store/windows
