OctoPublisher CLI .NET 10
Universal multi-store deployment automation engine for OctoCore applications. Publish Windows MSIX to Microsoft Partner Center and Android AAB/APK to Google Play in a single resilient CLI command.

Core Capabilities

Microsoft Store Ingestion

Auto-wraps MSIX into ZIP containers, sanitizes SAS tokens (+ to %2B), updates localized release notes, and safely skips on active certifications.

Google Play Publishing

In-memory RSA-SHA256 JWT signing for Service Accounts. Deploys AAB/APK to internal, alpha, beta, and production tracks without third-party actions.

Resilient Safe-Skip Engine

Exits cleanly with return code 0 when an active submission is already in certification or publishing to prevent breaking CI/CD pipelines.

Zero-Dependency Standalone

Single self-contained binaries available for Windows x64, Linux x64, and macOS Apple Silicon (ARM64) with startup times under 50ms.

Installation Guide

Choose between global installation via NuGet or standalone single-file binaries.

Requires .NET 10 SDK on Windows, macOS, or Linux.

Command Line

Pre-compiled native executables with embedded runtime for minimal containers.

Microsoft Store Module (mstore)

Automates the Partner Center Dev Center Ingestion API for Windows desktop packaging.

Publishing Package

Command Line
octopublish mstore publish \
  --package "./bin/Release/App.msix" \
  --app-id "9NZXP5WR803J" \
  --notes-dir "./packaging/whatsnew"

Inspect Status

Checks current submission state in certification pipeline.

octopublish mstore status --app-id 9NZXP5WR803J

Delete Draft

Removes pending uncommitted draft submission if stuck.

octopublish mstore delete-draft --app-id 9NZXP5WR803J

Google Play Store Module (playstore)

Direct integration with Google Play Developer API v3 using Service Account keys.

Publishing Bundle to Track

Command Line
octopublish playstore publish \
  --bundle "./android-dist/app-Signed.aab" \
  --package-name "com.octocore.obxodka" \
  --service-account "$PLAY_CONFIG_JSON" \
  --track "production" \
  --notes-dir "./packaging/whatsnew"
